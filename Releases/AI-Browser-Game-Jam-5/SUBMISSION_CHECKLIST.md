# SUBMISSION CHECKLIST — AI BROWSER GAME JAM 5
**Game:** MY SHADOW QUIT: THE LAST FLAME  
**Jam:** [AI Browser Game Jam 5 (itch.io)](https://itch.io/jam/ai-jam-5)  
**Theme:** TORCH  
**Release Archive:** `Releases/AI-Browser-Game-Jam-5/MY-SHADOW-QUIT-THE-LAST-FLAME-AI-JAM-5.zip`

Follow these step-by-step instructions to manually submit the game on itch.io without any automated scripts.

---

### STEP 1: LOG IN TO ITCH.IO & CREATE NEW PROJECT
1. Open your browser and log in to [itch.io](https://itch.io).
2. Go to your Creator Dashboard and click **"Create new project"** (or edit your existing project page for *MY SHADOW QUIT*).
3. Set **Title**: `MY SHADOW QUIT: THE LAST FLAME`
4. Set **Short description / Tagline**:
   > *Your shadow left you in the dark. Carry the last flame, command the void, and bring the light back through 50 cooperative puzzle-platforming chambers.*

---

### STEP 2: CONFIGURE PROJECT SETTINGS
1. **Classification:** Select **Games**.
2. **Kind of project:** Select **HTML** (*"You have a ZIP or HTML file that will be played in the browser"*).
3. **Release status:** Set to **Released** (or **In development** if preferred, but Released is recommended for jam entries).
4. **Pricing:**
   - Select **$0 or donate** or **No payments**.

---

### STEP 3: UPLOAD THE WEBGL ARCHIVE
1. Scroll down to the **Uploads** section.
2. Click **"Upload files"**.
3. Select the file:
   `/Users/logmat/Desktop/CLAUDE/MyShadowQuit/Releases/AI-Browser-Game-Jam-5/MY-SHADOW-QUIT-THE-LAST-FLAME-AI-JAM-5.zip`
4. Wait for upload to complete.
5. In the uploaded file row:
   - Check the box: **"This file will be played in the browser"**.
   - Check: **"Embed in page"**.

---

### STEP 4: EMBED & DISPLAY OPTIONS
1. Under **Embed options**:
   - **Viewport dimensions**:
     - **Width:** `1280` px
     - **Height:** `720` px
   - Check **"Automatically start on page load"**
   - Check **"Fullscreen button"**
   - Check **"Mobile friendly"** (if available)
   - Ensure **Orientation** is set to **Landscape**.

---

### STEP 5: ADD GAME DESCRIPTION & CONTROLS
1. Open [`ITCHIO_PAGE_EN.md`](file:///Users/logmat/Desktop/CLAUDE/MyShadowQuit/Releases/AI-Browser-Game-Jam-5/ITCHIO_PAGE_EN.md).
2. Copy the formatted description under section **3. FULL GAME DESCRIPTION** and paste it into itch.io's description editor.
3. Verify that the table of controls is cleanly formatted.

---

### STEP 6: CONFIGURE GENRE, TAGS & JAM THEME EXPLANATION
1. **Genre:** Puzzle / Platformer.
2. **Tags:** Add the suggested tags:
   `puzzle-platformer`, `pixel-art`, `torch`, `atmospheric`, `2d`, `co-op`, `dark-fantasy`, `html5`, `webgl`, `unity`, `singleplayer`, `game-jam`
3. If itch.io prompts for submission questions or jam theme details:
   - Copy the theme connection statement from `ITCHIO_PAGE_EN.md`:
     > *The torch is the central puzzle and narrative mechanic. Wielding or dousing the torch directly alters physical and spectral realities—revealing luminous pathways, igniting braziers, and casting shadows that your autonomous detached shadow must navigate to solve cooperative challenges across all 50 chambers.*

---

### STEP 7: SAVE & TEST RUN
1. Click **Save & view page**.
2. Run the game in your browser:
   - Verify that the loading bar progresses to 100%.
   - Click the canvas to verify focus and audio playback.
   - Test starting Level 1, navigating the menu, switching characters (`TAB`), using the torch (`T`), jumping (`Space` / `W`), and attacking (`J` / Left Mouse).
3. If everything runs smoothly, set visibility to **Public**.

---

### STEP 8: SUBMIT TO AI BROWSER GAME JAM 5
1. Visit the jam page: [https://itch.io/jam/ai-jam-5](https://itch.io/jam/ai-jam-5).
2. Click **"Submit your project"**.
3. Select **MY SHADOW QUIT: THE LAST FLAME** from the dropdown.
4. Fill in any required jam survey fields (tools used: Unity 6, Antigravity AI coding assistant, etc.).
5. Click **Submit**.
